# Data Structures & Algorithms practice

An automatically-updated collection of my accepted [LeetCode](https://leetcode.com/), to track my progress and solutions.

## Overview

* **Content:** All solutions contained in this repository have been **Accepted** on LeetCode.
* **Syncing:** This repo syncs every **Saturday** to pull all problems solved in the past week.
* **Structure:** Each directory is named after a LeetCode problem, and contains my solution and the problem description.
